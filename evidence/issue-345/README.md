It checks IFC4 EXPRESS/schema, unique GlobalIds, actual curve shapes, closed loops, independently calculated areas/perimeters and bounds. It also generates a foreign metre-unit IFC with rotated/translated site placement and no BIMCraft plot metadata; verify_foreign.py imports it through the real CLI. The repository validator additionally checks the standard house and full ifc-coverage.txt fixtures. Local results: plots 5 products/1 shape, foreign plots 5/1, house 50/46, coverage 354/351; zero problems in all four files.
